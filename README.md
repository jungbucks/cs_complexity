고등학교 2학년 정보과학 수업을 위한 세로 스크롤 발표 자료입니다. 교사가 화면을 보여 주며 설명하고, 학생은 읽으며 따라옵니다.

## 진행 방법

- **키보드**: `→`, `PageDown`, `Space`는 다음 장, `←`, `PageUp`은 이전 장입니다. 연달아 눌러도 누른 만큼 넘어가며, 펼친 내용이 있는 긴 장에서는 그 장 맨 위에서 한 번 멈춥니다. `↑`, `↓`는 일반 스크롤입니다. 펼친 내용이 길면 `PageDown`·`Space`는 먼저 그 장 안에서 내려갑니다.
- **화면 맞춤(데스크톱)**: 창 크기에 맞춰 16:9 슬라이드 한 장이 화면에 들어가도록 크기가 자동으로 맞춰지며, 정답을 열어도 한 화면 안에 들어갑니다. 선택 영역(`details`)을 펼치면 그 장만 아래로 길어집니다.
- **휴대폰(폭 800px 이하)**: 한 열로 바뀌고 장마다 세로로 길어질 수 있습니다. 넓은 표(17장)와 19장의 펼친 코드는 옆으로 밀어서 봅니다.
- **정답 토글**: Q1~Q7, 출구 질문 2개, 12장 복습, 17장 표 질문, 24장 삼각형, 27장 실습 결과, 29장 교사용 정답을 열고 닫을 수 있습니다. 열면 코드의 `# ?` 주석과 표의 `?` 칸이 실제 값으로 바뀝니다.
- **그래프**: 처음에는 전체 곡선을 보여 줍니다. 재생하면 n = 1부터 다시 그리며, 일시정지·처음으로가 가능하고 화면을 벗어나면 멈춥니다. 같은 함수는 모든 그래프와 표에서 같은 색입니다(n 파랑, n² 주황, n log n 갈색, log n 보라, 2ⁿ 짙은 남색 등).
- **Colab**: 코드 복사 버튼은 실행 횟수 주석을 빼고 코드만 복사합니다. 빈 노트북에 붙여넣고 Shift+Enter로 실행합니다. 수업 전에 학생 계정으로 링크를 한 번 확인하세요.
- 모션 축소 설정에서는 진입 효과를 생략하고, 그래프는 재생 시 최종값을 바로 표시합니다.

## 실행 횟수 주석

모든 코드 오른쪽에 `# 1회`, `# n회`, `# n²회`처럼 줄별 실행 횟수를 적었습니다.

- 세는 기준(교과서): 대입·반환 1회, `for` 줄은 한 바퀴마다 1회, `def` 줄은 세지 않음
- 퀴즈·출구 질문 코드의 주석은 `# ?`로 보이다가 정답을 열면 실제 횟수로 바뀝니다.
- 실습 코드(26장, 29장)의 주석은 n = 9 기준입니다.
- 19장 삽입 정렬 코드는 정렬 단원의 관례대로 **원소끼리 비교한 횟수**를 최선·최악으로 나누어 적었습니다. 이 코드는 자리를 찾으면 멈추는 일반적인 삽입 정렬이며, 교과서 코드(멈추지 않음)와의 차이를 같은 장에 밝혀 두었습니다.

## 실행과 배포

index.html을 브라우저로 열거나 이 폴더를 정적 서버로 제공하세요. 빌드나 설치가 필요하지 않습니다.
**assets 폴더(KaTeX, 글꼴)가 index.html과 같은 위치에 있어야** 수식과 글꼴이 표시됩니다.

## 글꼴과 수식

- 제목: Paperlogy Black/Bold
- 본문: Pretendard Medium
- 손글씨: Nanum Pen Script
- 코드: JetBrains Mono Medium(합자 비활성), 실행 횟수 주석: Pretendard
- 수식: KaTeX, HTML/MathML 출력. KaTeX를 불러오지 못하면 읽을 수 있는 대체 텍스트(예: 2n² + n + 2)가 보입니다.

배포 자산과 라이선스는 assets 폴더에 포함했습니다.
