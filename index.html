빅오(O): 증가율의 상한을 나타내는 기호

n이 충분히 클 때, T(n)이 어떤 함수 g(n)의
상수배를 넘지 않으면 T(n)은 O(g(n))이다.

예: 2n + 2는 n ≥ 1이면 4n(n의 4배)을 넘지 않는다.
그래서 2n + 2는 O(n)이다.

더 알아보기 · 빅오의 정확한 뜻
T(n) ≤ c · g(n)n ≥ n₀일 때 항상 성립하는 상수 c, n₀가 있으면 T(n)은 O(g(n))
g(n) = nc = 4n₀ = 1
선형 증가의 상한O(n)
‘정확히 n번’이라는 뜻이 아니야!

2n+2 → O(n)
2n²+n+2 → O(n²)
